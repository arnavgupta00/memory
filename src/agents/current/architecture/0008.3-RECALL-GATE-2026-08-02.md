# Architecture 0008.3 retrieval gate — 2026-08-02

## Decision

Reject the direct Architecture 0008.1 + 0008.2 combination. Do not run the
downstream BEAM canary or replace Architecture 0008 with it.

The experiment used the same 100-question Canary-A development slice and fresh
retrieval runs. All reported recalls are oracle measurements over opaque
session handles; oracle data was not exposed to the agents.

## Why the simple combination failed

Architecture 0008.2 proved that semantic retrieval can widen raw discovery,
but its gains are not stable under the existing admission process.
Architecture 0008.1's answer-shaped controller depends on the ordering and
content of its first candidate pool to decide which answer slots are covered
and what to search next. Adding dense results changed that evidence surface.
For several broad-history abilities, the controller treated noisy semantic
matches as coverage or generated less useful follow-up queries. The final V1
admission then discarded complementary evidence from the larger pool.

This is an interaction failure, not evidence that either component has no
value. The safe conclusion is that semantic discovery cannot simply be inserted
into both rounds of the answer-shaped workflow. A future combination would need
retriever-family-aware evidence control and admission, then a new clean gate.
