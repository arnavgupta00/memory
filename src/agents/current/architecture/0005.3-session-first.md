**Status:** frozen — [checkpoint](0005.3-CHECKPOINT-2026-07-27.md)  
**Prior:** [0005.2 checkpoint](0005.2-CHECKPOINT-2026-07-27.md) at **50/60 (83.3%)**, abstention **9/10**

## Decision

Keep the two-call tiered package. For `aggregate` / `order` only, expand SUPPORTING
beyond selector-chosen sessions into **entity/BM25-overlapping sibling sessions** from
the broad bundle. Pair with `select-v4` session-coverage guidance and a stricter
`none_found` rule for aggregates.

Lookup / preference packaging stays same-session-only so the 0005.2 abstention fix is
not reopened by noise.
