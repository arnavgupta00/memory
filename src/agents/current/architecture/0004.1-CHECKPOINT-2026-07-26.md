# Architecture 0004.1 checkpoint — 2026-07-26

## Checkpoint decision

Freeze the **medium-reasoning + evidenceTable** answerer on top of the 0004
BM25 backbone. This is the best measured development configuration so far:
**54/60 (90.0%)** on `dev-60-v1`.

`dev-60-v1` is contaminated by design and is **not** a blind or canary result.
Canary-2 confirmation of this configuration is a separately approved next step.
The prior canary-2 freeze remains **35/60** with `answer-v2-simple` and
`reasoning_effort: none` ([0004-CHECKPOINT-2026-07-26.md](0004-CHECKPOINT-2026-07-26.md)).

extractor/answerer was **not** built: the single-call evidenceTable already
captured most of the split’s benefit on this set.

## What is frozen

- Default `answer_prompt`: `answer-v2-evidence`
- Recommended answer settings: `reasoning_effort: medium`, `max_output_tokens: 16000`
- `reasoning_tokens` recorded in model usage when the provider returns them
- Historical configs preserve earlier arms (`answer-v2-simple` + none/low/medium,
  canary-2 simple at 35/60)
