# Architecture 0008.4 — answer-targeted slot retrieval

**Status:** implemented; retrieval gate failed; not selected or certified

**Frozen implementation baseline:** `3467f4d4`

## Hypothesis

Architecture 0008.1 improved complete selected bags by planning the shape of a
complete answer. Architecture 0008.2 improved raw candidate discovery with
semantic retrieval, but its question-derived query strings, rank-only fusion,
and unverified facet inheritance disrupted admission. Architecture 0008.3
confirmed that inserting dense hits directly into the 0008.1 workflow is not a
safe combination.

Architecture 0008.4 separates five concerns:

1. infer a fact-free answer contract and independent evidence slots;
2. generate literal BM25 queries and natural Voyage evidence descriptions;
3. preserve candidates by slot and retriever family before global ranking;
4. verify excerpt-to-slot support before claiming coverage;
5. run one evidence-driven follow-up and deterministically assemble a
   coverage-complete bag.

Unknown answer values must never be guessed into retrieval queries. Original
question search remains as a fallback lane. Oracle IDs, question IDs, benchmark
ability labels, and gold metadata are unavailable to all model calls.

## Experimental arms

- `answer-targeted-query`: query-only ablation. It tests answer contracts,
  retriever-specific queries, and slot-isolated discovery while retaining V1
  admission.
- `answer-targeted`: full 0008.4 workflow with verification, one follow-up
  round, and coverage-aware deterministic selection.

Both require the frozen semantic index. Explicit broad-history timeline cases
retain the already-tested Architecture 0008.1 wide sparse route during this
focused retrieval experiment; they are still included in aggregate results.

## Precommitted gate

Use the same 100-question Canary-A development slice. First compare query-only
discovery with fresh 0008.2. Run the full workflow only after wiring tests pass.
Do not run downstream answering unless the full arm reaches:

- candidate mean gold recall at least 72%;
- at least 55/100 full-gold candidate pools;
- selected-bag mean gold recall at least 65%;
- at least 48/100 full-gold bags;
- no material regression in protected high-performing abilities.

Candidate/bag gold and non-gold counts, per-slot queries, dense cosines, exact
chunk provenance, verification outputs, follow-up vocabulary, and final
selection must be logged for every case.

## Result

Architecture 0008.4 did not pass the precommitted retrieval gate.

The clean query-only 100-question run reached 64.74% candidate recall and
49/100 full-gold candidate pools, below Architecture 0008.2's 66.93% and
50/100. The first clean full-workflow run reached 66.37% candidate recall,
51/100 full candidate pools, 52.34% selected-bag recall, and 34/100 full bags.

A trace audit found that generic catalogs could omit dense excerpts after six
sparse excerpts. Family-balanced excerpt hydration plus a real permissive bag
fill improved selection directionally on a 20-question check. The final
100-question corrected run completed 93 cases before the OpenAI account ran out
of credits. Completed-case candidate recall was 67.86% and bag recall was
65.03%. Seven transport failures make that run unsuitable as an official score,
but even assigning perfect recall to all seven failures yields a maximum
possible 70.11% candidate recall, still below the frozen 72% threshold.

No downstream answer-quality or official BEAM judging run was started. Full
details are in `0008.4-RETRIEVAL-GATE-2026-08-02.md`.
