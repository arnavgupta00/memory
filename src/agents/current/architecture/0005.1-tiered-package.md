## Decision

Keep the two-call context service. Repair the Call 1 → Call 2 handoff:

- Selector emits `candidateStatus` / `missingRisk` (no closure `completenessNote`)
- No truncating turn catalog; IDs live on memory turn headers
- Tiered package: **SELECTED** then **SUPPORTING** (same sessions only)
- Empty selector → empty package (no ranked-session override)
- Answer prompt treats selector notes as hints; never answers `0` for entity mismatch
